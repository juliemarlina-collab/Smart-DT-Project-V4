What is Define?

Define is where your team makes sense of everything learned during Empathy. You analyse interviews, maps and persona evidence to write one clear user need statement before Ideation.

What students need to do

  • Review your Empathy Map, quotes and needs from Phase 01.
  • Build a User Persona using T05.
  • Cluster findings into insights and write a User Need Statement using T06.
  • Pass the Define quiz, save both templates, then submit Define.

Common mistakes to avoid

  • Do not invent persona details. Use real evidence.
  • Do not confuse a need with a solution.
  • Group notes by meaning, not by speaker.
  • Do not skip the insight. It explains why the need matters.
