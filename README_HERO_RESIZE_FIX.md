# Smart DT Hero Resize Fix

This package contains:

```text
css/smartdt-hero-resize-fix.css
```

## Purpose

This CSS makes hero images bigger and more suitable for:

- mobile phone,
- tablet,
- desktop / PC.

It specifically improves the Progress page hero while also resizing all DT pages, Dashboard, Projects and Profile heroes.

## Upload location

Upload the file to:

```text
css/smartdt-hero-resize-fix.css
```

## Add this line to every page that needs the bigger hero

Place this after your existing CSS links:

```html
<link rel="stylesheet" href="css/smartdt-hero-resize-fix.css"/>
```

Recommended order:

```html
<link rel="stylesheet" href="css/smartdt.css"/>
<link rel="stylesheet" href="css/smartdt-responsive-fix.css"/>
<link rel="stylesheet" href="css/smartdt-hero-resize-fix.css"/>
```
